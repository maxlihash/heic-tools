About HEIC Tools

Built for a simple reason: you shot photos on your iPhone, they're in HEIC format, and you just want to open them anywhere — without uploading to someone else's server.

What it does

  • Convert HEIC to JPG — universal format, opens everywhere
  • Convert HEIC to PNG — lossless, for editing
  • Convert HEIC to WebP — smaller file size for web
  • Convert HEIC to PDF — document ready

Why in-browser matters

All conversion runs entirely in your browser using WebAssembly. Your photos never leave your device — no upload, no server processing, no privacy risk. You can verify this: open DevTools and check the Network tab. After the page loads, there are zero upload requests.

How to add to your home screen

Install HEIC Tools like an app for quick access, even offline:

iPhone / iPad (Safari)

Open this page in Safari → tap the Share button (box with arrow) → "Add to Home Screen" → Add.

Android (Chrome)

Open in Chrome → menu "⋮" → "Add to Home Screen" / "Install app" → confirm.

Windows / Mac (Chrome / Edge)

Click the install icon in the address bar, or find "Install this app" in the browser menu.

Is it really free?

Yes. Completely free. No signup, no account, no limits on number of files. Supported by minimal advertising.

Tech

Static HTML + CSS + vanilla JS. HEIC decoding via heic2any (libheif compiled to WebAssembly). Batch compression via JSZip. No backend, no database, no build step. Hosted on Cloudflare Pages.
